# Security Policy

Theoros software is designed to run on spacecraft. We take every report
seriously.

## Reporting a vulnerability

Do not open a public issue. Email **security@theoros.space** with:

- the affected repository, component and version or commit,
- a description of the issue and its impact,
- steps to reproduce, if available.

We acknowledge reports within two working days and aim to provide an
assessment within ten working days. We credit researchers who report
responsibly, unless they prefer otherwise.

## Supported versions

Only the latest minor release of each component receives security fixes,
unless a customer agreement states otherwise.
